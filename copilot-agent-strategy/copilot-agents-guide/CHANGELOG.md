# Changelog

All notable changes to the Copilot Agents Guide are documented here.

## 4.1.0 - 2026-09-15

### Corrected

- Word, Excel, and PowerPoint Agents now state that a paid Microsoft 365 Copilot license is required, replacing the earlier claim that they were available to users with or without a Copilot license.
- Aligned FastTrack scope descriptions across all paths with the published Microsoft service description, and removed the deployment-channel qualifier from the Copilot Studio path.
- Replaced the blanket statement that Agents Toolkit publishing is unsupported in Microsoft 365 Government tenants with a pointer to the current, environment-specific support status.
- Softened the Cowork prerequisite statement to reflect that a spending policy selecting Cowork acts as the access control, and to direct readers to the current licensing and usage-based billing prerequisites.
- Scoped automatic Microsoft Entra Agent ID creation to the standard harness, and corrected the removal of environment-level opt-out to May 2026.
- Qualified Copilot Studio GitHub Copilot harness capabilities: memory is a production-ready preview and workflows as tools is a preview.
- Removed an unsourced statement about how FastTrack assistance is scoped from the Agent Builder path.

### Added

- Cowork local browser use, including that it is off by default, requires tenant admin enablement, and runs only in Cowork on the web with Microsoft Edge 150 Stable 2 or later.
- A central FastTrack scope summary covering agent fundamentals, management and governance, Work IQ enablement, consumption billing and spending controls, usage measurement, and Microsoft Agent 365, with the corresponding out-of-scope boundaries.
- A link to the published FastTrack service description for Microsoft Agent 365.

### Changed

- Advanced the core guidance review date to September 15, 2026.
- Synchronized the README version footer with the catalog front matter.

## 4.0.1 - 2026-09-09

- Added `interactiveKind: guide` catalog metadata so the catalog labels this resource an "Interactive guide". Guide content is unchanged.

Earlier version history is available in the repository Git log.
